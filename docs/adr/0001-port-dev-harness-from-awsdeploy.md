# ADR-0001: 開発ハーネス（GitHub Flow・Issues・ADR・フック）を awsdeploy から引き継ぐ

- **状態**: 有効
- **決定日**: 2026-08-29
- **関連**: 移植元 [awsdeploy](https://github.com/toshiki0102/awsdeploy)（ADR-0001 / 0009 / 0012 に対応する判断）

## 背景（何に困っていたか）

このリポジトリは Claude Code とエージェントの仕組みを学ぶためのサイトで、
awsdeploy（AWS の Notes アプリ）とは中身が全く違う。**ゼロから運用ルールを決め直すか、
既存の運用を持ち込むかを選ぶ必要があった。**

awsdeploy 側では数か月かけて次を整備し、実際に回っていた。

- GitHub Flow（`type/説明` ブランチ → PR → Squash merge）
- GitHub Issues をやることの正とし、ラベルをブランチ名と同じ語彙に揃える
- ADR（1決定=1ファイル・追記のみ）
- Git フック（秘密情報スキャン / `main` 直接 push 拒否 / ADR 書き忘れ検知）

## 決定

**上記4つをこのリポジトリにも入れる。** ファイルは awsdeploy からコピーし、
このリポジトリの実態に合わせて削る。

**引き継がないもの**: AWS 固有の内容（デプロイ順序ルール、コスト方針、Terraform 関連）。

**形を変えるもの**: 「テストが緑になるまで完了としない」という原則は、**文章のページには
当てはまらない**。コード（クイズ部品など）にはテストを書き、文章には別の完了基準を置く。
具体的な基準は憲法（`.specify/memory/constitution.md`）が持つ。

**あわせて適用する判断**: `CLAUDE.md` から Spec Kit の管理区画（`<!-- SPECKIT START -->`
マーカー）を削除する（awsdeploy の ADR-0011 と同じ理由）。

## 理由

**運用ルールの価値は、身につくまで繰り返すことにある。** リポジトリごとに違うルールを
使うと、どちらも身につかない。同じ語彙・同じ手順を別のプロジェクトでも使うことで、
習慣として定着する。これはこのサイト自体の目的（学習）とも一致する。

**移植コストがほぼゼロだった。** フック3本は対象ディレクトリ（`.specify/` ·
`.claude/skills/`）が新リポジトリにも存在するため、そのまま意味を持つ。Issue テンプレートと
ADR のルールはプロジェクト非依存。書き直しが要ったのは CONTRIBUTING.md の AWS 部分だけ。

**public リポジトリなので、awsdeploy でできなかったことが1つできる。** サーバー側の
ブランチ保護（Ruleset）が無料で使える。awsdeploy は Private + Free で使えず、クライアント側
フックで代替していた。フックは手元のクローンしか守らないので、こちらではサーバー側も併用する。

**受け入れた犠牲**: 1人で学習ノートを書くだけの作業に対して、手順がやや重い。
Issue を立ててブランチを切って PR を出す手間が、1行の誤字修正にもかかる。
これは「小さな直しは Issue 不要」という例外で緩和する。

## 検討した代替案

| 案 | 内容 | 却下理由 |
|---|---|---|
| A | ルールを作らず `main` に直接コミットする | 学習ノートなら現実的だが、**このサイトの題材そのものが「AI と共同で開発する進め方」**であり、自分がその型を使っていないのは説得力が無い。履歴も読めなくなる |
| B | ゼロから軽量な運用を設計し直す | 設計に時間を使うぶん、書く時間が減る。既存の運用は実際に回っていた実績があり、作り直す理由が無い |
| C | 一部だけ持ち込む（Issues だけ、など） | 4つは互いに噛み合っている（Issue のラベル → ブランチ名 → コミット接頭辞）。切り離すと語彙の対応が崩れる |

## 結果（この決定が生むもの）

- awsdeploy と同じ手順で作業できる。切り替えコストが無い。
- 「次に書くページ」を Issue に積める。
- 判断の理由が残る（この ADR 自体がその1本目）。
- **受け入れたコスト**: 1行の直しにも手順がかかる。
- **将来の宿題**: サーバー側ブランチ保護（Ruleset）はまだ設定していない。public なので無料で
  使えるため、CI が整ったら入れる。

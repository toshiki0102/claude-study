# ADR-0006: Mermaid は `vitepress-plugin-mermaid` で描く（VitePress 1.x + mermaid 11 に固定）

- **状態**: 有効
- **決定日**: 2026-09-12
- **関連**: Issue #8 / [憲法「技術と公開の制約」](../../.specify/memory/constitution.md) / [research.md](../../specs/001-learning-site-first-page/research.md)（F-1 / F-2 / F-5）

## 背景（何に困っていたか）

憲法 II は「説明の中心は Mermaid 図。図の無い解説ページは書かない」と定め、憲法「技術と公開の
制約」は「図は Mermaid。画像化した図は差分が読めなくなるため原則として使わない」と定める。
**図はこのサイトの主役であり、外せない。**

ところが **Mermaid は VitePress の標準機能ではない**（[research.md](../../specs/001-learning-site-first-page/research.md) F-2）。
` ```mermaid ` フェンスをそのまま書いても描画されない。何らかの追加の仕組みが要る。

同時に、バージョンの地形が単純ではなかった（2026-09-12 時点、[research.md](../../specs/001-learning-site-first-page/research.md) F-1 / F-5）。

- VitePress の安定版は **1.6.4**。2.x は **アルファ**（2.0.0-alpha.20）
- `vitepress-plugin-mermaid` の最新は **2.0.17（2024-09-24 公開）** — **約2年更新が無い**。
  peer は `vitepress: ^1.0.0` / `mermaid: 10 || 11`
- `mermaid` の最新は **12.0.0（2026-09-10 公開）** — プラグインの peer の範囲外

## 決定

**`vitepress-plugin-mermaid` を使い、次の組み合わせに固定する。**

| パッケージ | 範囲 | 理由 |
|---|---|---|
| `vitepress` | `^1.6.4` | 安定版。2.x はアルファ |
| `vitepress-plugin-mermaid` | `^2.0.17` | VitePress 1.x 向けの peer |
| `mermaid` | `^11` | プラグインの peer が `10 \|\| 11`。**12 は入れない** |

設定は `withMermaid()` で VitePress の設定を包む形にする（プラグインの想定する使い方）。

**この決定は「いま動くもの」を選んだのであって、長期に賭けたものではない。** VitePress 2 が
安定版になった時点で選び直す。そのときは**この ADR を置き換える新しい ADR を書く**。

## 理由

**憲法が Mermaid を要求している以上、選択肢は「どう描くか」だけで、「描かない」は無い。**

**プラグインを選んだのは、VitePress 1.x 向けとして最も使われており、設定が `withMermaid()` の
一行で済むから。** 自前で書く案（案 C）は、SSR 時の扱い・ダークテーマ切り替え・Mermaid の
非同期描画をすべて自分で面倒を見ることになる。**このリポジトリの目的は Claude Code を学ぶこと
であって、Mermaid の描画基盤を書くことではない。** 学習の本筋から外れた自作コードは、
壊れたときに直す気力が続かない。

**受け入れたリスクを明記する: このプラグインは約2年更新が無い。** VitePress 2 が安定版に
なったとき、プラグインが追随していなければ**乗り換えが必要になる**。それを「起きうること」
として今ここに書き残す。動かなくなってから理由を探すことになるのを避けるため。

**mermaid を `^11` に固定するのは、最新の 12 が peer の範囲外だから。** 新しいほうが良いという
理由で 12 を入れると、警告を無視した状態が常態化して、本当に壊れたときに気づけない。

## 検討した代替案

| 案 | 内容 | 却下理由 |
|---|---|---|
| A | VitePress 2.x（アルファ）＋ 2 に対応した新しいプラグイン | 土台がアルファ。1本目のページを公開まで通すという目的に対してリスクが釣り合わない |
| B | `vitepress-mermaid-renderer` など、より新しい別プラグイン | ズーム・全画面・ダウンロードなど、いま要らない機能を伴う。VitePress 1.x での動作は未確認（＝断定できない） |
| C | ` ```mermaid ` フェンスを自前のコンポーネントで描画する | 依存は減るが、SSR・テーマ切り替え・非同期描画を自作することになる。学習の本筋から外れる |
| D | 図を画像（PNG/SVG）で用意する | 憲法「技術と公開の制約」が明示的に却下済み（差分が読めなくなる） |

## 結果（この決定が生むもの）

- ` ```mermaid ` フェンスをそのまま書けば図になる。執筆の手数が増えない
- 図がテキストのまま残り、差分が読める（憲法どおり）
- **受け入れたリスク**: プラグインが約2年更新されていない。VitePress 2 への移行時に
  詰まる可能性がある。そのときは新しい ADR で置き換える
- **制約**: `mermaid` を 12 系に上げられない。依存の更新時にこの制約を思い出す必要がある

# ADR-0002: 学習ノートサイトの憲法を「4原則」で定める

- **状態**: 有効
- **決定日**: 2026-08-29
- **関連**: Issue #2 / [ADR-0001](./0001-port-dev-harness-from-awsdeploy.md) /
  `.specify/memory/constitution.md`

## 背景（何に困っていたか）

Spec Kit を導入した時点で `.specify/memory/constitution.md` はテンプレートのままだった
（`[PROJECT_NAME]` `[PRINCIPLE_1_NAME]` …）。Spec Kit の全工程（`/speckit-specify` →
`-plan` → `-tasks`）はこの憲法を「守るべき規範」として参照するため、空のままでは以降の
仕様書が拠り所を持たない。

一方このリポジトリは**ソフトウェア製品ではなく、自分ひとりのための学習ノートサイト**で、
テンプレートが例示する原則（Library-First / CLI Interface / Integration Testing /
Observability）は前提からして噛み合わない。「読者が自分ひとり」「長文を読み通せない」
「Claude Code の情報が数か月で古びる」という、このサイト固有の制約を規範にする必要があった。

## 決定

**憲法を4原則で書く。** 5番目の原則の枠はテンプレートから削除する。

1. **推測を断定で書かない**（交渉不可）— 時点を明記し、公式ドキュメントで裏取りする
2. **図が主役・1ページ1概念** — Mermaid が本体、スクロール3画面で分割
3. **ページの完了条件は「クイズ3問」** — 4択クイズを3問作れないページは公開しない
4. **コードにはテストを書く** — 失敗するテストが先、緑でなければマージしない

バージョンは **1.0.0**（初回制定、2026-08-29 批准）。手順（ブランチ運用・Issue 運用）は
憲法には書かず、`CONTRIBUTING.md` と GitHub Issues にリンクするだけに留めた。

## 理由

**「クイズ3問」を完了条件にしたことが、この憲法の中心。** 学習ノートの失敗は「書いたのに
身についていない」ことで、それは普通のテストでは検出できない。3問作れるかどうかは、理解の
穴とページの詰め込みすぎを同時に検出する、**機械的に判定できる代理指標**になる。

**原則を4本に絞ったのは、守れない原則を持たないため。** アクセシビリティ、表示速度、SEO
なども挙げられたが、読者が自分ひとりである以上どれも実際には検査されない。検査されない
原則は憲法を形骸化させ、本当に守るべき4本の重みまで下げる。

**犠牲にしたもの**: ページを量産する速度と網羅性。原則 II と III により、1ページごとに図と
クイズ3問が必要になり、書ける本数は確実に減る。**カバー範囲より、残ることを取った。**

## 検討した代替案

| 案 | 内容 | 却下理由 |
|---|---|---|
| A | 憲法を書かず、テンプレートのまま進める | Spec Kit の全工程が拠り所を失う。`/speckit-plan` の Constitution Check が空回りする |
| B | Spec Kit の例示原則をほぼそのまま使う | ソフトウェア製品（ライブラリ・CLI・サービス）向けで、学習ノートサイトの制約と噛み合わない |
| C | 原則を5〜7本に増やす（アクセシビリティ・表示速度・SEO 等） | 読者が自分ひとりで、実際には検査されない。守られない原則は憲法全体を形骸化させる |
| D | 完了条件を「文字数」や「章立て」にする | 書いた量は理解の証拠にならない。原則 III が防ごうとしている「分かった気」をむしろ助長する |

## 結果（この決定が生むもの）

- Spec Kit が参照する規範が確定し、`/speckit-specify` 以降に進めるようになった。
- 各ページに「図・要点3行・クイズ3問」という**明確な完了条件**ができた。
- 受け入れたコスト: **1ページあたりの制作コストが上がり、書ける本数が減る。**
- 将来の宿題: `.githooks/checks/upstream-override-adr.sh` は `^\.specify/` 全体を
  「上流に逆らう変更」とみなすため、**テンプレートを埋めるだけの `constitution.md` 更新でも
  push が止まる**。本来これは上流が想定した使い方であり、除外を検討する余地がある
  （この ADR はその検査を通すためにも必要だった）。

# ADR-0004: クイズは frontmatter に持ち、設問は問題文のハッシュ、ページは手書きの `quizId` で識別する

- **状態**: 有効
- **決定日**: 2026-09-12
- **関連**: Issue #8 / [spec.md](../../specs/001-learning-site-first-page/spec.md)（FR-003 / FR-018 / FR-019） / [ADR-0005](./0005-page-completion-check.md)

## 背景（何に困っていたか）

憲法 III は「各ページ末に4択クイズ3問」「成績はブラウザに保存し、間違えた問題を再出題」と定める。
これを実装に落とすには、答えの無い問いが3つ同時に立っていた。

1. **3問をファイルのどこに書くか。** ここが決まらないと、完了条件の機械検査（FR-023）が
   「どこを読めばよいか」を決められない。
2. **成績をどの設問に結びつけるか。** spec は識別子を手で振らないと決めている（FR-019）。
   ならば何から算出するのか。
3. **「どのページの」成績かをどう表すか**（FR-018）。ページを整理して移動・改名したとき、
   成績が消えてよいのか。

制約: サーバーもアカウントも持たない（憲法）。成績は読者の端末内にのみ存在する。

## 決定

**1. クイズ3問はページ Markdown の frontmatter に書く。**

```markdown
---
title: エージェントループ
lastVerified: 2026-09-12
quizId: agent-loop
quiz:
  - q: ツールの実行結果は、次にどこへ渡るか
    choices: [モデルへの入力, ユーザーの画面, ログファイル, 破棄される]
    answer: 0
  # 3問
---
```

**2. 設問の識別子は「問題文 `q` のテキストだけ」から算出する。** 選択肢と正解はハッシュに含めない。

**3. 「どのページか」は frontmatter の `quizId` を手で書く。** URL パスは使わない。
`quizId` の書き忘れ・重複は機械検査で落とす（[ADR-0005](./0005-page-completion-check.md)）。

## 理由

**frontmatter を選んだのは、機械検査が最も壊れにくいから。** YAML をパースして
`quiz` の要素数を数えれば済む。本文中に書く案では、検査が「本文から設問らしきものを探す」
作業になり、書き方の揺れでいつでも壊れる。**検査が信用できないなら、機械検査を置く意味が無い。**
犠牲にしたのは執筆時の近さ — 本文を書きながらクイズを書けず、ファイルの上下を往復する。

**識別子を問題文だけから算出するのは、選択肢の誤字修正で成績を消さないため。**
成績は3問ぶんしかなく、こまめに消えると「理解の記録」として機能しない。
**受け入れた代償: 正解の選択肢を差し替えても同じ設問とみなされ、古い正誤がそのまま残る。**
これは実害が出た時点で ADR を書き直して識別子の材料を広げる（そのときはこの ADR を置き換える）。

**`quizId` を手で書くのは、ページの置き場所をあとから変えられるようにするため。**
2本柱（「使い方」「仕組み」）の切り分けは書きながら変わる見込みが高く、URL をキーにすると
整理のたびに成績が消える。**整理を思いとどまらせる設計は、学習ノートとして間違っている。**
代償は1ページあたり1行の手作業で、書き忘れは機械が止める。

## 検討した代替案

| 案 | 内容 | 却下理由 |
|---|---|---|
| A | 本文末尾に `<Quiz :questions="[...]" />` と書く | 検査が本文中の JS リテラル解析になり壊れやすい。ビルド前に識別子を確定できない |
| B | ページごとに別ファイル `*.quiz.yml` | 検査はしやすいが1ページが2ファイルに割れ、片方だけ直す/消す事故が起きる |
| C | 識別子を「問題文＋選択肢＋正解」から算出 | 正解の差し替えを検出できる利点はあるが、選択肢の誤字修正でも成績が消える。3問しかない成績では失う側が重い |
| D | 識別子を手で振る（`id: q1`） | spec の FR-019 が明示的に却下済み（手で管理する手間を避ける） |
| E | ページのキーに URL パスを使う | 書く手間はゼロだが、ページを移動・改名すると成績が消える。整理の抑止力になる |

## 結果（この決定が生むもの）

- 機械検査が YAML のパースだけで書ける → [ADR-0005](./0005-page-completion-check.md) が成立する
- 設問の識別子をビルド時にも実行時にも同じ純関数で算出できる（テストしやすい）
- ページを別フォルダへ移しても成績が残る
- **宿題**: 正解の選択肢だけを直したとき、古い正誤が残る。気づく手立ては今は無い
- **宿題**: `quizId` の重複・書き忘れを検査で止める必要がある（検査側の要件になった）

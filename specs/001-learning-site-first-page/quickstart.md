### S-1. テストが通る（憲法 IV）


### S-2. 完了条件を満たさないページは公開を止める（FR-023 / SC-009）

```bash
# 1本目のページのクイズを3問→2問に減らしてから

```

**期待**: **赤**。`quiz-count  クイズが 2 問しかありません（3問必要）` のように、

確認したら元に戻す。

### S-3. ページが読める（US1）

```bash
npm run docs:dev
```

ブラウザで 1本目のページを開き、**目で**確かめる:

- 冒頭に要点3行がある
- Mermaid 図が**描画されている**（コードのまま出ていない → [ADR-0006](../../docs/adr/0006-mermaid-rendering.md) が効いている）

### S-4. クイズが動く（US2）

同じ画面のページ末尾で:

1. 1問目の選択肢を選ぶ → **その場で正誤が出る**
2. 同じ問題の別の選択肢を選ぼうとする → **選べない**（FR-011）
3. わざと間違える → **正解が示される**（FR-012）
4. 3問すべて答える → **「3問中 n 問正解」が出る**（FR-013）

### S-5. 成績が残り、間違えた問題だけやり直せる（US3）

1. 1問だけわざと間違えて、3問とも回答する
2. **ページをリロード** → 前回の正誤が残っている（FR-016）
3. 「間違えた問題だけもう一度」→ **間違えた1問だけが出る**（FR-017）
4. そこで正解する → 記録が正解に更新される
5. もう一度リロード → **再挑戦の導線が消えている**（全問正解のため / US3-4）

### S-6. 保存が使えなくても最後まで解ける（FR-020 / SC-005）

ブラウザの**プライベートウィンドウ**、またはサイトのデータ保存をブロックした状態で S-4 をやり直す。

**期待**: 3問すべてに回答でき、採点結果が出る。エラー表示もページの停止も無い。
リロードすると成績は消えている（**それが正しい**）。

**期待**: 回答によって発生するリクエストが**0件**。
